# Originali degli asset

Questa cartella e' l'area di lavoro locale per foto originali, file Illustrator,
EPS, PDF e documenti ricevuti dal team. Il suo contenuto e' ignorato da Git per
non appesantire il repository e non viene pubblicato sul sito.

1. Conservare l'archivio condiviso definitivo su OneDrive.
2. Copiare temporaneamente i nuovi file in `INBOX/`.
3. Preparare la versione WebP con i comandi descritti in
   `../AGGIORNA-SITO.md`.
4. Versionare soltanto il risultato ottimizzato dentro `public/`.

Non inserire password, link privati o dati personali non destinati al sito.
